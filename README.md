# E-Commerce Sales Analytics

## Project Overview

An end-to-end analysis of the Global Superstore 2016 dataset using Microsoft Excel to evaluate sales, profitability, customer segments, regional performance, product performance, discount behavior, and monthly trends.

## Dataset

- 51,290 transaction-line records
- 24 original columns
- Period: 2012–2015
- Source: Global Superstore 2016

## Tools & Techniques

- Microsoft Excel
- Power Query
- PivotTables
- Power Pivot / DAX
- Excel formulas
- Data visualization
- Dashboard design

## Business Questions

- What is the overall sales and profitability performance?
- How does performance change over time?
- Which regions contribute most to profit?
- Which sub-categories generate or destroy profit?
- How does profitability change across discount levels?
- How do customer segments differ?

## Key KPIs

| KPI | Value |
|---|---:|
| Revenue | ₹12,642,501.91 |
| Profit | ₹1,467,457.29 |
| Orders | 25,728 |
| Customers | 17,415 |
| Profit Margin | 11.61% |

## Analysis

### Monthly Performance
Analyzed monthly revenue, profit, orders, profit margin, and month-over-month growth.

### Regional Performance
Compared revenue, profit, orders, and profit margin across regions.

### Product Performance
Analyzed category and sub-category revenue, profit, orders, and margin.

### Discount Analysis
Grouped discounts into bands and compared profitability across discount ranges.

### Customer Segments
Compared Consumer, Corporate, and Home Office performance using total and per-unit metrics.

## Key Findings

- Overall revenue was ₹12.64M with ₹1.47M profit and an 11.61% profit margin.
- Profitability varies substantially across regions and sub-categories.
- Tables generated negative profit despite generating significant revenue.
- Higher discount bands were associated with progressively lower profit margins.
- Customer-segment differences in total revenue and profit were strongly influenced by segment size.

## Dashboard

The Excel dashboard combines KPIs, monthly trends, regional profitability, sub-category performance, discount profitability, customer-segment performance, and interactive slicers.
